# Contributing

Thanks for considering a contribution! Here's how to add a project:

1. Fork this repo
2. Pick the right folder: `BEGINNERS`, `Intermediate`, or `ADVANCED`
3. Add your `.py` file with a clear, descriptive filename
4. Keep code clean and commented
5. Open a Pull Request describing what your project does

## Guidelines
- One project per file
- No external dependencies unless necessary (note them in a comment at the top if required)
- Test your code before submitting

That's it — happy coding! 🐍
